# ABOUT 

THIS IS A PYTHON BASED FILE-INTEGRITY-CHECKER THAT DETECTS UNAUTHORIZED CHANGES, MODIFICATIONS AND MISSING FILES WITHIN A SPECIFIED FILE.

THIS USES SECURE HASH ALGORITHM-256, A CRYPTOGRAPHIC HASHING FUNCTION TO CHECK THE INTEGRITY OF THE FILES  

# TOOLS AND ENVIRONMENT 

1. THIS HAS BEEN DEVELOPED IN VISUAL STUDIO CODE WITH A PURE PYTHON IMPLEMENTATION ALONG WITH IT'S STANDARD LIBRARIES.

2. IT USES HASHLIB FOR SECURE CRYPTOGRAPHIC HASHING.

3. IT IS COMPATIBLE WITH ALL THE OPERATING SYSTEMS THAT SUPPORT PYTHON.

# FEATURES

1. THIS CREATES BASELINE HASHES FOR ALL THE FILES IN THE MONITORED DIRECTORY.

2. DETECTS MODIFIED, MISSING OR NEWLY ADDED FILES.

3. CAPABLE OF HANDLING LARGE FILES USING CHUNK READING.

4. STORES HASH VALUES IN A JSON FILE.

5. PROVIDES CLEAR RESULTS FOR DIFFERENT FILE CHANGES.

# USAGE

1. CREATE A DIRECTORY MANUALLY OR BY PROGRAMMING TO TEST.
   
2. SET THE MONITORED DIRECTORY PATH.
   
3. RUN THE INITIALIZATIONS TO CREATE THE BASELINE HASHES.
   
4. PERFORM THE INTEGRITY CHECKS.
   
5. DIRECTORIES CAN BE TAKEN FROM THE SYSTEM ITSELF, ENSURING SAFETY.

#SECURITY APPLICATION
CAN BE USED FOR MALWARE DETECTION, UNAUTHORIZED MODIFICATIONS AND ACCIDENTAL CHANGES IN IMPORTANT DIRECTORIES.
